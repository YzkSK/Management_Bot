# 強度共通の検知種別におけるセレクタ非表示

## 目的

NGワードと招待リンクは強度設定で検知条件が変化しない。設定画面で変更効果のないセレクタを出さず、強度共通であることを明確にする。

## 方針

Dashboard側に、強度が検知条件へ影響しない種別を判定する小さな関数を置く。該当する行ではセレクタと保存操作を表示せず、`強度共通` と現在の共通条件を詳細表示する。DB・APIのpreset値は互換性のため保持する。

## 対象

- 非表示: `ngword`、`invite_link`
- 従来どおり選択可能: `flood`、`duplicate_content`、`mention_spam`、`link_spam`、`new_account_guard`、`raid`

## テスト

- NGワード・招待リンクの行に強度セレクタがないことを確認する。
- 他の種別には従来どおりセレクタがあることを確認する。
- 強度共通の詳細文言を確認する。
