# パッケージ依存図の層構造化

## 目的

`docs/architecture/02-package-dependencies.md` の依存図で、共通基盤へ集中する個別の線を束ね、全体の依存レイヤーを一目で把握できるようにする。

## 方針

- Mermaid の `classDiagram` を `flowchart` に置き換える。
- 図では `config`、共通基盤（`shared` / `db` / `core`）、Dashboard・ログ系、Bot機能群の4層だけを示す。
- 図に個別のパッケージ間の矢印は描かない。正確な個別依存は既存の「境界」表に残す。
- DB・共有型・イベントバスを共通基盤としてまとめ、Dashboard・ログ系とBot機能群がそれを利用する関係を表す。

## 非対象

- 実装コードとパッケージ構成の変更。
- 他のアーキテクチャ図の変更。
- 「境界」表への依存関係の追加・削除。

## 検証

Mermaid ブロックが Markdown 内で正しく閉じていること、図と「境界」表のパッケージ群が一致することを目視確認する。
